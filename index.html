⚡ API & Portal Sync Explained
🔌 What is an API?

An API (Application Programming Interface) is a standardized communication bridge between computers. When your college portal opens, its frontend calls an API on the server (like GET /api/student/attendance) which returns structured JSON data with your attended lectures.

🛡️ Why Direct College ERP APIs Cannot Link to Public Webpages
  • CORS Security: Web browsers strictly block client-side websites from making unauthorized background requests to external university ERP servers.
  • Session & CAPTCHA Auth: SVKM/NMIMS SAP portals require 2FA/CAPTCHA logins, active session tokens, and encrypted cookies.
  • 100% Privacy Advantage: By using Bunk Bank's Weekly Report PDF Importer, no login passwords leave your device, and all data is processed 100% locally in your browser memory!
